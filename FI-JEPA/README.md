# FI-JEPA

**Current status: proposal stub — M0 / E0**

This directory does not currently contain an implemented or validated financial JEPA system. At the time of the 2026-08-29 repository audit it contains this README, a license, and an effectively empty `init.py`; there are no retained tests, datasets, experiment outputs, baselines, or reproduction commands here.

The name therefore represents a research direction, not a completed project or result.

## Promotion gate

Before this project can be described as implemented, it must add:

1. a falsifiable research question and null hypothesis;
2. a defined financial/economic prediction or representation task;
3. dataset identity, provenance, license, split policy, and leakage controls;
4. at least one strong simple baseline;
5. executable model code;
6. deterministic smoke tests;
7. a frozen bounded experiment configuration;
8. raw machine-readable outputs with seed/config/commit provenance;
9. an evidence ledger separating actual results from expected/planned results;
10. a reproduction command that works from a clean environment.

## Scientific integrity boundary

Do not report simulated performance as realized investment return. Do not use future information in a historical test. Do not claim predictive alpha, market impact, user adoption, or research novelty without corresponding evidence.

Project status is tracked in `../registry/projects.json` and should be promoted only after its stated gate is actually verified.
