# Finance4All four-month execution control — 28 September 2026

Planning window: **25 September 2026 to 25 January 2027**.

This file turns the 48-project portfolio into an execution queue. It does not convert targets into achievements or held projects into active programs. The machine-readable source of truth for this branch is `registry/finance4all_4month_projects.json`.

## Portfolio operating rule

Finance4All has 48 queued projects, but the cycle is executed through eight delivery pods and an explicit gate system. Core projects are worked first. Gated projects receive readiness work—canonical-state reconciliation, specifications, evidence contracts and reviewer/data requirements—but do not start outcome-bearing runs, participant delivery, external recruitment or public launches until their activation gate is satisfied.

Every project remains `HOLD_UNTIL_OWNER_REVIEW` in the registry until a real accountable owner and reviewer accept the scope. This is intentional: a generated task assignment is not an assignment to a person.

## Definition of done

A project is not complete because a README, mock-up, local prototype, model run, event or outreach draft exists. Completion requires the project's original acceptance evidence: retained artifacts, reviewer/reproduction evidence where required, explicit limitations, and an auditable closeout decision.
