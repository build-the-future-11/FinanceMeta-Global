## Shared evidence contract

Every promoted project in this group must record source version/vintage, availability semantics, reproducible transforms, reviewer, explicit limitations and a claim ledger. Quantitative model work additionally requires the F4A-01/02/04 integrity stack before result-bearing evaluation.

If a project lacks data compatibility, a reviewer or an exact question at the M1 review, the correct state is a documented hold rather than a rushed M2 launch.
