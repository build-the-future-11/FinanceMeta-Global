## 4. Borrowing cost

Two hypothetical loans have the same principal, the same repayment period, and no fees. Loan A has a 6% annual interest rate. Loan B has an 8% annual interest rate.

1. Under these controlled assumptions, which loan has the lower borrowing cost?
2. If one loan instead charged additional fees, what broader comparison measure should you inspect along with the contract terms?
3. Why would it be misleading to compare one loan's APR directly with another loan's interest rate?

## 5. Risk and expected return

Which response best reflects the general risk-return relationship?

A. High promised return proves the investment is safe.

B. Greater potential return generally comes with greater risk, and no investment return is guaranteed merely because it is advertised.

C. Risk only matters after an investment loses money.

D. Diversification makes any promised return guaranteed.

Explain your answer in one or two sentences.
